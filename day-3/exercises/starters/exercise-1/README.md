# Starter for exercise 1

Fell behind, or no project yet? Start [exercise 1](../../exercise-1-tanstack-query.md) from here. This is the result of the catch-up at the start of the day: tabs Items and Bag, a list, a stack and a detail screen, with the items in an array.

1. Get the course repo: `git clone https://github.com/Kevinvandenhoek/inholland-react-native-course.git`, or **Code → Download ZIP** on GitHub. Copy this folder out of it to your own place and name it `Pokedex`.
2. In that folder:

   ```bash
   npm install
   npx expo start
   ```

3. Scan the QR code with Expo Go. Works? Then put it in git:

   ```bash
   git init
   git add .
   git commit -m "Start from the exercise 1 starter"
   ```

   Then push it to your own GitHub repo.
