# InHolland React Native Course

Four days of React Native for ICT students at InHolland. One app runs through all four days: a Pokédex built on [PokeAPI](https://pokeapi.co/) and this [Figma design](https://www.figma.com/design/dsgGXcu5WELIvRW90m5308/Pokemon-Code-Challenge).

| Day | Topic | |
|---|---|---|
| 0 | Introduction: React Native, web vs. native, Expo | [material](./day-0/README.md) |
| 1 | Fundamentals: components, styling, navigation | [material](./day-1/README.md) |
| 2 | Data and debugging: state, TanStack Query, SQLite, agent mode | [material](./day-2/README.md) |
| 3 | Your own product: structure, spec and issues, hand-in, use of AI | [material](./day-3/README.md) |

Slides: `https://kevinvandenhoek.github.io/inholland-react-native-course/day-<n>/slides/<deck>.html`. Each day's README links to its decks.

The **final assignment** is in [day-3/README.md](./day-3/README.md).
