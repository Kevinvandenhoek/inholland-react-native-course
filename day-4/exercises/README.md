# Day 4 exercises

These three are the start of your final assignment. Everything you make today
stays in your own repo and gets handed in.

1. [Exercise 1: your own repo](./exercise-1-repo.md)
2. [Exercise 2: your spec and your issues](./exercise-2-spec.md)
3. [Exercise 3: your first feature with the agent](./exercise-3-first-feature.md)

## Rules

- Agent mode is allowed from here on. One task at a time, always reviewed.
- A new chat for every issue. Clean start for the agent, and your chat history stays sorted per issue.
- Every agent task ends with asking until you can explain it, then updating your instructions.

## Helpful commands

- `npx expo start` starts the dev server, `--clear` when things look stale
- `npx expo lint` and `npx tsc --noEmit` check your code
- `gh repo create` and `gh issue create` (GitHub CLI, needed from exercise 1 on)
- `closes #12` in a commit message closes that issue
